# Changelog

## 0.4.0 - 2026-09-10

- Redesigns the card as a complete person overview for phones and watches.
- Adds optional activity, charging, connection, Wi-Fi, update, app and storage
  fields plus reusable custom detail entities.
- Adds an optional in-card back button and clickable detail fields.
- Correctly formats Unix timestamps from watch GPS sensors.
- Uses dashboard theme variables first, Home Assistant variables second and
  ordinary color values as the final fallback.

## 0.3.1 - 2026-09-10

- Adds standard Home Assistant and ordinary color fallbacks to status colors.

## 0.3.0

- Initial standalone release.
